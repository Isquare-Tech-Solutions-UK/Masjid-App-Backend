Download OpenAPI specification:

Masjid App Support: support@masjid-app.com License: Proprietary

API for Masjid Application - Prayer times, events, announcements, campaigns, and donations management.

Authentication

  • Admin APIs: JWT Bearer Token in Authorization header
  • Member APIs: API Key in X-API-Key header
  • Webhooks: Stripe signature verification

Rate Limits

  • Admin APIs: 100 requests/minute per user
  • Member APIs: 60 requests/minute per API key
  • Auth endpoints: 10 requests/minute per IP
